Nota para ejecutar esta parte del proyecto:

La cadena de conexión utiliza el servidor SQL Server de mi computadora (DESKTOP-PA2RE64). 
Para ejecutar el proyecto en otro equipo, es necesario cambiar el nombre del servidor en la cadena de conexión por el correspondiente a la instancia de SQL Server instalada en su equipo.
También se debe crear la base de datos DanceFlow utilizando el script de SQL incluido en el repositorio.
